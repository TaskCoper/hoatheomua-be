## Statement

> Xóa mẫu thiệp trong hệ thống quản trị là xóa mềm.

## When

Admin xác nhận xóa mẫu thiệp.

## Then

Hệ thống cập nhật isDelete = true trong Core Database.

## Except

Hệ thống không được xóa cứng mẫu thiệp khỏi Core Database.
