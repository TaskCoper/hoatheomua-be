## Statement

> Ảnh tải xuống phải được chuẩn hóa theo định dạng PNG và giữ nguyên chất lượng ảnh.

## When

Hệ thống chuẩn bị file tải xuống.

## Then

Hệ thống trả file ảnh ở định dạng PNG, giữ nguyên resolution và không cắt giảm chất lượng.

## Except

Không trả file ở format khác ngoài PNG cho chức năng này.
