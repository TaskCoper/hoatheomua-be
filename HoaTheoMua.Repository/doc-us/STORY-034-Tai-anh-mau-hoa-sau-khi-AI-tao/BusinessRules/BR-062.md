## Statement

> Ảnh tải xuống phải là file kết quả chính thức đã được hệ thống gắn logo.

## When

Hệ thống trả file tải xuống cho khách hàng.

## Then

Hệ thống trả đúng file kết quả chính thức đã được lưu sau quá trình tạo mẫu hoa AI.

## Except

Chức năng tải xuống không được gắn lại, thay đổi hoặc tạo phiên bản logo khác.
