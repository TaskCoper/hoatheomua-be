#### EstimateShippingFree
1. Happy case
- Company address tồn tại, NhanhVn trả về đủ sản phẩm cho tất cả `request.Items`, AhaMove trả về list service estimate hợp lệ → kết quả trả về đúng `{ ahamoveResult, productNhanhResult }`
- `request.OrderTime > 0` → `IdleUntil` phải bằng `OrderTime`.
- `request.OrderTime == 0` (hoặc âm) → `IdleUntil` phải là `null`.
- Kiểm tra request gửi lên NhanhVn có đúng `Filters.Id` = danh sách `ItemId` từ request không.
- Kiểm tra `AhamoveItem.Num` map đúng với `request.Items[i].Number` theo `ItemId`.
- Kiểm tra `PackageDetail` map đúng Height/Weight/Length/Width từ `x.Shipping`.
- Header `Authorization` gửi đúng token lấy từ config (ưu tiên config DB, fallback `_nhanhVnOption`/`_ahaMoveOption` nếu config DB không có).
2. Edge case

| Case                                                                                 | Kỳ vọng                                                                                                                                                                                                        |     |     |
| ------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --- | --- |
| `CompanyAddresses` không có bản ghi nào (hoặc toàn bộ `IsDeleted = true`)            | throw `Exception("Company address not found")`                                                                                                                                                                 |     |     |
| `companyAddress.Remarks` null                                                        | gán null vào `Remarks` (do `!`), không throw NullReferenceException                                                                                                                                            |     |     |
| NhanhVn API trả HTTP lỗi (4xx/5xx)                                                   | throw `BadRequestException` với message chứa status code                                                                                                                                                       |     |     |
| NhanhVn trả `200` nhưng body rỗng                                                    | ERR_INVALID_FORM_FIELDS                                                                                                                                                                                        |     |     |
| NhanhVn trả `Data = null`/ không parse ra được                                       | throw new BadRequestException("NhanhVnResponse returned null or empty data");                                                                                                                                  |     |     |
| **Bug tiềm ẩn**: NhanhVn trả về sản phẩm có `Id` không nằm trong `request.Items`     | `request.Items.First(item => item.ItemId.Equals(x.Id))` sẽ throw `InvalidOperationException` (Sequence contains no matching element) — nên test case này để xác nhận có cần try/catch hay validate trước không |     |     |
| `request.Items` rỗng                                                                 | NhanhVn trả `Data` rỗng → `itemsRequest`/`packageDetailRequest` rỗng, vẫn gọi AhaMove với item rỗng — kiểm tra hành vi có hợp lý không (có thể AhaMove reject)                                                 |     |     |
| `x.Prices.Retail` là số thập phân (vd 15000.99)                                      | `(int)` cast sẽ **cắt phần thập phân**, không làm tròn — nên test rõ hành vi cast này có đúng ý đồ nghiệp vụ không                                                                                             |     |     |
| Trùng `ItemId` trong `request.Items`                                                 | `.First()` chỉ lấy phần tử đầu, có thể sai số lượng nếu người dùng gửi trùng item                                                                                                                              |     |     |
| AhaMove API trả lỗi HTTP                                                             | throw `BadRequestException` với message chứa status code                                                                                                                                                       |     |     |
| AhaMove trả `null` hoặc list rỗng                                                    | throw `BadRequestException("Ahamove returned null or empty data")`                                                                                                                                             |     |     |
| Config trong DB có nhưng thiếu 1 vài key (vd chỉ có `nhanhvn.app_id`, thiếu `token`) | phải fallback đúng sang `_nhanhVnOption`/`_ahaMoveOption` cho từng key riêng lẻ                                                                                                                                |     |     |
| HttpClient bị timeout / network exception                                            | hiện tại không có try/catch → exception (`TaskCanceledException`, `HttpRequestException`) sẽ bay thẳng ra ngoài — nên test để xác nhận đây là hành vi mong muốn hay cần catch lại                              |     |     |
| JSON trả về sai schema (parse exception)                                             | `ReadFromJsonAsync` throw `JsonException`, không bị catch — tương tự cần xác nhận behavior                                                                                                                     |     |     |
